# AGENTS.md

Project-specific guidance for coding agents. See `README.md` for the full
architecture, test list and known limitations.

## Ground rules

- tlang is self-hosting. A language or compiler change must land in both
  `Bootstrap/` (stage 0, Python) and `tcomp.tl` (self-hosted), and stage 2 and
  stage 3 must remain byte-identical.
- The release version lives in `VERSION`. Stage 0 reads it in
  `Bootstrap/__init__.py`; `Tools/gen_version.py` generates the
  `Runtime/version_gen.tl` constant that `tcomp.tl` imports. A release bumps
  `VERSION`, regenerates, and adds a `CHANGELOG.md` entry; CI checks that the
  generated file is current.
- `Bootstrap/runtime.py`, `Bootstrap/builtin_spec.py` and `Tools/gen_kinds.py`
  are sources of truth. `Runtime/runtime_gen.tl`, `Runtime/kinds_gen.tl`,
  `Runtime/builtins_gen.tl`, `Runtime/builtins_dispatch_gen.tl`,
  `Bootstrap/kindrules_gen.py` and `Bootstrap/builtins_gen.py` are generated;
  never edit them by hand. Plain builtins listed in `GENERATED_BUILTINS` need a
  spec entry and a runtime helper, but no hand-written branch in `tcomp.tl`.
- `Kernel/font8.s` is generated by `Tools/make_font.py`; never edit it by hand.
  Artwork is not a build artifact: it is the canvas buffer, saved to and loaded
  from TLFS (`fs_save`/`fs_load` selectors 2 and 3), so no picture costs space
  in the 98,304-byte load window.
- Match the style of the surrounding code and do not add dependencies.
- `taarch64` is always lowercase.
- `--freestanding` and the machine builtins also land in both compilers. A
  kernel build emits `call __k_<name>` and takes `print`, `alloc`, `exit` and
  the diagnostics from `Kernel/kruntime.s`; never add a syscall to that path.
- The boot path is `Kernel/mbr.s` (512-byte MBR, 192-sector load window) plus
  `Kernel/boot.s` (identity map, long mode). `Kernel/build.sh` reads
  `IMAGE_SECTORS` from `mbr.s` and fails when the image outgrows that window;
  keep the window and the check in step. The EDD buffer offset is 16 bits and
  carries into the segment past 64 KiB. The window ends at `0x1FE00`, where the
  MBR's VBE mode-info block goes, with the boot-info block at `0x1FF00`; both
  must stay outside the loaded image, or the copy to 1 MiB plants BIOS data in
  `.text`.
- The desktop's files live on the IDE slave disk (`-drive ...,index=1`), reached
  with `ata_read`/`ata_write`; the master holds the kernel image and is never
  written. `Tests/kernel_test.py` boots twice over one filesystem image to check
  that a file survives.
- A program needs exactly one parameterless `fn main()`; a function, global
  or struct defined twice, or a call to a function that is never defined, is a
  compile error. Both compilers must report these with a source position and
  the same message text; `Tests/errors_test.py` covers them.
- Array indexing is bounds-checked by default, and string indices are
  checked for negatives. Keep `Tests/bounds_test.py` passing in both
  compilers, and keep the generated runtime's `__t_bounds_fail` path in sync.
- Update `README.md` when a compiler size, timing, test count or the layout
  changes.

## Build and check

```bash
python3 Tests/version_test.py    # stage 0 and tcomp.tl report tcomp 1.2.2
python3 Tests/run_tests.py       # golden output, exit status, binary size
python3 Tests/diff_test.py       # optimized and --no-opt builds agree
python3 Tests/compare_test.py    # stage 0 and self-hosted compiler agree
python3 Tests/builtins_test.py   # builtin metadata contract
python3 Tests/runtime_test.py    # runtime dependency and assembly contract
python3 Tests/freestanding_test.py     # kernel image has no syscalls and links
python3 Tests/machine_builtins_test.py # machine builtins and kernel runtime
python3 Tests/kernel_test.py     # boots the desktop, clicks and types at it (77 = skipped)
python3 Tests/sourcemap_test.py  # imported-file diagnostics
python3 Tests/env_test.py        # environment lookup in both compilers
python3 Tests/bounds_test.py     # checked indexing and runtime guards
Tools/selfhost.sh --verify       # stages 2 and 3 must be byte-identical
```

Run the broader suites when the change touches them:

```bash
python3 Tests/programs_test.py
python3 Tests/errors_test.py
python3 Tests/modules_test.py
python3 Tests/floats_test.py
python3 Tests/io_test.py
```

## Generated modules

After changing the runtime, the kind rule or builtin metadata, regenerate before
running tests:

```bash
python3 Tools/gen_runtime.py
python3 Tools/gen_kinds.py
python3 Tools/gen_builtins.py
```

All three scripts accept `--check`; `Tools/selfhost.sh` fails on stale output.

## Tests

Add cases under `Tests/Cases/` as `NAME.tl`, optionally with `NAME.in`,
`NAME.out` and `NAME.code`. `Tests/run_tests.py --update` rewrites golden
files, so inspect the diff before trusting it.
